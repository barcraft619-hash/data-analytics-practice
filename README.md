# Аналитика интернет-магазина

## Описание проекта

Практическая работа по созданию базы данных SQLite
с использованием языка программирования Python.

## Цель проекта

Создать базу данных интернет-магазина и научиться
выполнять SQL-запросы для анализа продаж.

## Используемые технологии

- Python 3
- SQLite
- SQL
- Visual Studio Code

## Структура базы данных

Название базы данных: shop.db

Название таблицы: sales

Поля таблицы:
- id — идентификатор записи
- product — название товара
- category — категория товара
- price — цена товара в тенге
- quantity — количество проданных товаров
- sale_date — дата продажи

## Данные

- Всего записей: 20
- Категорий: 4
- Товары: техника, аксессуары, офис, мебель

## Выполненные SQL-запросы

1. SELECT — получение всех записей.
2. WHERE — фильтрация товаров дороже 20 000 тенге.
3. WHERE — поиск товаров определённой категории.
4. ORDER BY — сортировка товаров по цене.
5. COUNT — подсчёт количества записей.
6. COUNT DISTINCT — подсчёт категорий.

## Запуск проекта

Сначала создайте базу данных:

```bash
python setup_db.py
```

Затем проверьте данные:

```bash
python check_db.py
```

## Результат

Создана работающая база данных интернет-магазина
с 20 записями и четырьмя категориями товаров.
